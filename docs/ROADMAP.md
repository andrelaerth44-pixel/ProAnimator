# ProAnimator Roadmap

## Phase 0 — Foundation (Current)
- [x] Repository structure
- [x] Architecture documentation
- [x] Core vision and principles

## Phase 1 — Canvas & Brush Foundation (Priority)
- [ ] Multi-module Gradle setup
- [ ] Basic Skia/Compose canvas
- [ ] Stylus pressure capture
- [ ] Simple brush system
- [ ] Layer management (add, delete, reorder, opacity, blend modes)
- [ ] Basic undo/redo
- [ ] Project save/load (simple format first)

## Phase 2 — Timeline Core
- [ ] Multi-track timeline UI
- [ ] Playhead and playback
- [ ] Flipbook mode + Onion Skin
- [ ] Content types: Drawing + Flipbook
- [ ] Basic keyframe system (position, scale, rotation, opacity)

## Phase 3 — Advanced Animation
- [ ] Perform mode (record motion)
- [ ] Warp / Distort keyframes
- [ ] Filter keyframes (blur, HSB, noise...)
- [ ] Grouping and hierarchical animation
- [ ] Audio track support

## Phase 4 — Performance & File Format
- [ ] `.pan` format v1 with streaming
- [ ] Eternal undo history
- [ ] High-resolution canvas support (4K+)
- [ ] Resource management and caching strategy
- [ ] Vulkan rendering path (experimental)

## Phase 5 — Export & Polish
- [ ] Professional export (MP4 H.264/HEVC, PNG sequence, transparent video)
- [ ] Advanced Export studio
- [ ] S-Pen optimization
- [ ] High refresh rate (120/144Hz) support
- [ ] Tablet-specific UI adaptations

## Phase 6 — Ecosystem
- [ ] Brush import/export
- [ ] Template system
- [ ] Community features (optional)

---

**Estimated effort for a solid MVP (Phase 1 + 2):** 4–8 months with a small dedicated team.  
**Full professional parity:** Multi-year effort.
